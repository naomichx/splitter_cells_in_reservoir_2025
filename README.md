# splitter_cells_in_reservoir_2025

This repository contains the code associated with the paper "The Quasi-Systematic Nature of Splitter Cells" (https://doi.org/10.1101/2024.06.07.597927).

Some files in the analysis section were adapted from the Google SVCCA tutorial and are derived from the original implementation available at https://github.com/google-research/svcca.
